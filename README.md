# Crypto Futures Trader

Торговый бот для разгона маленьких депозитов на криптовалютных фьючерсах.

## Стратегия

### Инструмент 1: Круглые уровни (Support & Resistance)
- Круглые числа ($1000, $5000, $10000…) — психологически важные уровни.
- Возле них скапливаются ордера, формируя зоны поддержки/сопротивления.
- Уровень — это зона, а не линия. Цена может немного не дойти или слегка пробить.
- Чем «круглее» число, тем сильнее уровень.

### Инструмент 2: Свечной анализ тренда
- Визуальное сравнение зелёных (бычьих) и красных (медвежьих) свечей.
- Если зелёных свечей больше и их тела крупнее → восходящий тренд.
- Если красных больше и крупнее → нисходящий тренд.
- Нет явного перевеса → боковик, не торгуем.

### Вход в сделку
- **LONG**: цена у зоны поддержки + бычий тренд по свечам. SL под зоной, TP на следующем сопротивлении.
- **SHORT**: цена у зоны сопротивления + медвежий тренд по свечам. SL над зоной, TP на следующей поддержке.

### Риск-менеджмент
- Фиксированный % от депозита на сделку (по умолчанию 2%).
- Плечо вычисляется автоматически из размера позиции и стоп-лосса.
- Жёсткий лимит на максимальное плечо.

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env
# Заполните .env своими API-ключами
```

## Использование

```bash
# Dry-run (без реальных ордеров)
python main.py --once

# Указать пару и таймфрейм
python main.py --symbol ETH/USDT --timeframe 1h --once

# Живая торговля
python main.py --live

# Настройка риска
python main.py --risk 1.5 --leverage 5 --live
```

## Структура

```
trader/
  round_levels.py    — расчёт круглых уровней поддержки/сопротивления
  candle_analysis.py — свечной анализ тренда (бычье/медвежье доминирование)
  signals.py         — генерация торговых сигналов
  risk.py            — риск-менеджмент и расчёт размера позиции
  exchange.py        — обёртка над ccxt (данные, ордера)
  engine.py          — торговый движок (цикл анализа и исполнения)
  config.py          — загрузка конфигурации
main.py              — точка входа (CLI)
```

## Предупреждение

Торговля фьючерсами с плечом сопряжена с высоким риском. Используйте бот на свой страх и риск. Всегда начинайте с dry-run режима.
